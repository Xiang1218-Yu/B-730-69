# 悦行山海 - 旅游景区官方网站

面向“旅游景区官方网站”课程/作业的前端演示项目：包含登录、首页、景点列表与详情、攻略、住宿、票务、导览、关于我们等模块；适配 H5 移动端与桌面端响应式布局。

## 技术栈

- Vue 3 + Vite
- Element Plus
- Vue Router 4
- Pinia（状态管理）

## 配色与视觉规范

- 主色：天空蓝 `#4A90E2`
- 辅色：浅绿 `#7DD181`
- 背景：米白 `#F5F7FA`

## 本地运行

```bash
npm install
npm run dev
```

构建与预览：

```bash
npm run build
npm run preview
```

## 页面与路由

- `/login`：登录/注册（验证码、记住密码、忘记密码）
- `/me`：用户中心（账号信息、数据概览、退出登录）
- `/home`：主页面（轮播、快捷入口、热门景点推荐、主题路线、精选活动）
- `/spots`：景点列表页（支持搜索 query 与分页）
- `/spot/:id`：景点详情页（图册预览、介绍、信息卡、评价提交/展示、相关推荐、在线咨询）
- `/guides`：游玩攻略（列表 + 弹窗详情）
- `/stay`：住宿预订（酒店/民宿筛选、日期筛选、预订提交）
- `/tickets`：票务中心（票型选择、数量、订单提交与支付入口弹窗）
- `/map`：景区导览（交互式地图示意：景点定位/服务设施图层）
- `/about`：关于我们

## 项目结构

- src/components：通用组件（导航栏、页脚、验证码等）
- src/pages：页面（登录、首页、景点列表、景点详情、住宿预订、游玩攻略、票务中心、景区导览、关于我们）
- src/assets：静态资源（可放置自制景区实拍图/矢量图标）
- src/router：路由配置
- src/store：状态管理与演示数据（景点/路线/活动/评价/订单等）
- src/utils：工具函数（图片占位/封面生成等）

## 核心功能（对照需求）

- 登录页面
  - 登录/注册切换（演示：注册用户保存在 localStorage）
  - 验证码校验
  - 记住密码（本地存储）
  - 忘记密码找回入口（弹窗演示）
- 用户中心
  - 右上角入口（登录后显示用户名与“游客”角色标签；未登录显示“登录/注册”按钮）
  - 页面数据概览：收藏 / 评价 / 住宿预订 / 票务订单（本地存储）
- 主页面（含推荐列表）
  - 顶部导航：Logo、主导航、搜索框（跳转景点列表页并带 query）
  - 轮播图：3 张核心景点图 + slogan
  - 热门景点推荐：卡片式推荐 + “查看更多”跳转到景点列表页
  - 主题游玩路线：亲子/徒步/日落等标签化展示
  - 精选活动面板：活动时间 + 报名入口（未开始提示弹窗）
  - 底部区域：联系方式、地址导航、公众号二维码、版权栏
- 景点详情页
  - 景点评分、收藏/分享、在线咨询
  - 图册预览（点击放大）
  - 详细介绍：历史背景、亮点、开放时间/门票/交通
  - 游客评价：星级评分 + 图文评论提交后实时刷新
  - 相关景点推荐
- 加分拓展页面
  - 住宿预订：酒店/民宿筛选、日期筛选、预订提交（表单校验）
  - 游玩攻略：列表（封面/作者/阅读量）+ 详情内容（行程/注意/美食）
  - 票务中心：票型选择、数量、订单提交与支付入口
  - 景区导览：交互式示意地图（景点定位/路线示意/服务设施图层）

## 数据与持久化

- 登录态、注册用户、收藏、评价、预订/票务订单均使用 localStorage（便于纯前端演示）
- 演示数据入口：`src/store/data.js`

## 访问与权限

- 默认入口：访问根路径 `/` 会进入登录页
- 路由拦截：除 `meta.public` 页面外，未登录访问会被重定向到 `/login?redirect=...`，登录后自动回跳

## 动效与适配

- 页面切换：`App.vue` transition 渐入
- 懒加载：图片统一使用 `loading="lazy"`，详情页图册使用 `ElImage` 预览能力
- 响应式：大屏多列网格，小屏单列/双列；导航栏小屏折叠为抽屉菜单

## 素材说明

- 当前默认封面/轮播图：由 `src/utils/media.js` 生成（支持 SVG 占位图与公共 CDN 图片）
- 若需替换为“自制景区实拍图”，建议将图片放入 `src/assets`，并在 `media.js` 中改为返回本地资源路径

## 浏览器测试建议
